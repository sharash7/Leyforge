# Leyforge R7 W3 proof runtime

This nested project and Python fixture package implement only the governed PRD-07 W3 fluid, editable-vessel, collision and moving-frame proof surfaces. They consume the certified W0 dependency lock and the relevant W1/W2 fixture capabilities without changing any prior evidence set.

The Godot project under `server_probe/` is an exported proof process. It is not a production game project and does not open R8. It exposes exact provider/build identity, vessel/world frame conversion and a PhysicsServer3D shape-contact corpus while canonical hull, fluid, ownership and derived-property authority remains in the bounded fixture model.

`python -m tools.r7_w3_runtime fixture-launch-validation --implementation-commit <sha>` is the certification-only launch gate. It produces fresh client and headless exports, resolves each executable through the returned `ArtifactManifest.artifact_path`, launches both exported fixtures in self-report mode and proves the W3 execution journal and RUN/EVID registry are unchanged. It never enters the fixture proof mode, calls a proof objective, or allocates an actual identity.

W3 performance figures remain candidate-comparison evidence rather than final hardware or support budgets. Readiness allocates no RUN/EVID identities; actual execution resolves them from the authoritative high-water mark immediately before execution.
