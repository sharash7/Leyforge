# Leyforge Document Set 26

## Oceans, Maritime Civilisation, Vessels and Naval Systems Expansion

**Release:** v0.1  
**Status:** Complete design-document set  
**Documents:** 26A–26O  
**Formats:** DOCX and Markdown

Document Set 26 expands Leyforge's post-POC production design into a complete maritime civilisation layer covering oceans, liquids, coasts, underwater play, environmental simulation, voxel vessels, shipbuilding, vessel authoring, ports, crews, trade, fleets, piracy, navies, naval combat, marine ecology, progression, registries, technical implementation, QA and integration.

## Package Layout

- `DOCX/` — formatted design-bible documents.
- `Markdown/` — editable/source-friendly Markdown equivalents.
- `DOCUMENT_SET_INDEX.md` — ordered document index and scope summary.
- `MANIFEST.txt` — packaged file inventory.
- `SHA256SUMS.txt` — SHA-256 checksums for package integrity verification.

## Authority and Integration Notes

- Set 26 builds on the post-Atlas governance established by Document Set 25.
- Specialist documents retain authority for their own systems; 26O is the technical and integration capstone rather than a replacement for 26A–26N.
- The current implementation direction is Godot with Summer Engine-assisted development.
- Production world content is seed-driven rather than dependent on fixed POC geography.
- Exact balance constants and performance caps remain prototype/evidence driven where the documents mark them as such.
