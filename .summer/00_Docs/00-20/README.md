## Important Production Locks

The reconciled Foundation adopts:

- Godot + Summer Engine as the active technical direction.
- POC scenarios as Archived Validation rather than active production authority.
- One gameplay rule / one owner.
- Deterministic seed-generated production worlds.
- Generated Base + Persistent Delta world persistence.
- Canonical Block/Item single-identity rule.
- Block Inventory Projections instead of duplicate recoverable Block Items.
- Seven top-level settlement needs:
  - Housing
  - Provisions
  - Health
  - Work
  - Safety
  - Infrastructure
  - Morale
- Simulation Depth separated from Performance Profile, Difficulty and Accessibility.
- Documents 19 and 20 separated into settlement planning versus functional construction/project authority.
- Sets 27–30 specialist ownership consumed through interfaces rather than duplicated.
