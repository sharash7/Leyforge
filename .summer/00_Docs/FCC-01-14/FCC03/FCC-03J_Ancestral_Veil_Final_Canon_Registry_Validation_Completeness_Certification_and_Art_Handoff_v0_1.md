The Ancestral Veil is certified as:

> **A complete persistent realm where memory, recognised identity, history, remembrance, reflection, route relationships and spirit-active matter can have physical consequences, while the realm remains a self-contained world rather than an automated afterlife simulation.**

The following are final realm-local prohibitions:

- player death does not automatically send the player to the Veil;
- NPC/creature death does not automatically create a Veil entity;
- the Veil is not a database containing every dead person;
- spirits are not generic crafting resources;

- Necropolis is not inherently evil;
- undeath is not equivalent to Void corruption;
- Predator Dark is not equivalent to Void corruption;
- realm-wide narrative time replacement is not adopted;
- player hunger/survival is not replaced by a realm-only need system.

These boundaries are **blocking canon** for later implementation and art.

# 19. Block, Item and Physical-Identity Certification

FCC-03 adopts the Leyforge single-definition rule:

> **If a placeable object is recovered as the same physical object, it has one canonical Block definition and inventory uses a generated Block Inventory Projection.**

A separate Item is justified when:

- mining/harvesting transforms the source;
- processing creates a portable material form;
- dismantling intentionally returns components rather than the placed object;
- the portable component has a materially distinct lifecycle.

Examples:

- Memory Stone Brick recovered as itself → one Block + Block Inventory Projection;
- Soul Silver ore mined into raw Soul Silver ore/concentrate → distinct source Block and resource Item are valid;
- Spirit Clay deposit harvested into clay → distinct source Block and portable resource are valid;
- Veil Lantern recovered as itself → Block-owned inventory projection;
- Soul Silver Ingot / Plate / Wire → true portable Items.

Blocking failures include:

- duplicate same-identity Block + Item definitions;
- cosmetic-state duplicate species/blocks;
- material × shape registry explosion;
- generic Ancestral copies of universal furnaces, chests, looms or ordinary tools without a distinct contract.

# 28. Cleansing, Stabilisation and Restoration Certification

FCC-03 certifies these as separate concepts.

## Cleansing
Removes or reduces an active harmful state such as contamination, possession/influence or Void corruption.

## Stabilisation
Stops further decline or secures a dangerous state without necessarily restoring full function.

## Restoration
Repairs, replaces or re-establishes useful physical, ecological, historical, political or route function.

## New Stable State
A valid persistent outcome that differs from the site's previous form but is internally stable and authoritative.

A restored location does not need to return to a pristine historical condition.

Valid post-crisis futures include:

- restored historical form;
- reformed polity;
- shared claimant governance;
- ecological replacement;
- safe decommissioning;
- preserved ruin;
- transformed civic use;
- new settlement identity.
