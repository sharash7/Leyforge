# 1. Purpose

FCC-06I defines the authoritative corruption, regional-state, realm-event and cross-realm interface canon for the **Impossible Deep**.

It owns:

- the distinction between native Impossible Deep phenomena and genuine Void corruption;
- the eight principal regional state families;
- state compatibility and coexistence;
- bounded deterministic state transitions;
- the twelve principal realm-event families;
- event warnings and precursors;
- persistent aftermath;
- unloaded/far-simulation requirements;
- regional consequences for settlements, routes, ecology, structures and dungeons;
- authority/event integration;
- corruption overlays;
- cross-realm interface boundaries;
- current rebuild-scope realm relationships;
- future-feature placeholders that must not become current dependencies;
- state/save persistence requirements;
- final interface handoff to global reconciliation.

FCC-06I does **not** finalise:

- exact event frequencies;
- exact simulation tick rates;
- exact corruption-cleansing recipes;
- exact AI scheduling;
- exact regional-state probability weights;
- final visual effects;
- final shader values;
- final sound cues;
- exact quest scripts;
- exact cross-realm portal recipes;
- final global event namespace IDs unless already established elsewhere.

Those are deferred to implementation, global systems and later art/reconciliation work.

# 2. Canon Statement

Impossible Deep is a naturally impossible realm.

Its normal reality already contains:

- inverted gravity;
- multi-centre gravity;
- folded distance;
- Stoneflow;
- extreme pressure;
- Blackwater Vault-Seas;
- fossil continents;
- world-scale caverns;
- seismic forests;
- Coreward fractures.

These are **native realm laws and ecologies**.

They are not evidence of Void corruption.

---

# 3. Void Corruption Provenance Rule

A state is classified as **Void corruption** only when actual Void provenance exists.

Valid provenance may include:

- a confirmed Void fracture;
- Void-contaminated entity;
- Void-tainted material;
- known corruption spread;
- authored cross-realm Void event.

Impossible Deep content must not use “corrupted” as a synonym for:

- dangerous;
- ancient;
- hostile;
- physically impossible;
- dark;
- deep;
- unstable.

---

# 4. Explicit Non-Corruption Examples

The following are not Void corruption by default:

- Pressure Surge;
- Stoneflow;
- Seismic Swarm;
- Gravity Drift;
- Fold Shift;
- Blackwater darkness;
- toxic gas;
- Deepfire Ember;
- Fossil Crown;
- ancient Coreworms;
- Pressure Titan;
- Blackwater Matriarch;
- Seismic World-Beasts;
- Inverted Caverns;
- Coreward Chasms;
- Blackwater Vault-Seas.

A dangerous native phenomenon remains native unless explicit Void provenance changes it.

# 5. Corruption State-First Rule

Void corruption should normally appear as:

- state;
- overlay;
- variant;
- contamination;
- behavioural alteration;
- regional modifier.

A new permanent Block, Item, creature or material definition is only justified where corruption causes **irreversible transformation into genuinely distinct matter or entity identity**.

This prevents registry explosion.

# 6. Principal Regional State Roster

Impossible Deep has exactly **eight principal regional state families**:

1. **Stable Strata**
2. **Pressure Surge**
3. **Seismic Swarm**
4. **Gravity Drift**
5. **Stoneflow Cycle**
6. **Blackwater Upwelling**
7. **Fold Shift**
8. **Void-Corrupted State**

These are regional environmental-state families.

They are not mutually exclusive by default.

---

# 7. Stable Strata

## 7.1 Identity

**Stable Strata** is the baseline known/settled environmental state.

It represents a region whose pressure profile, gravity profile, routes, Stoneflow, seismic activity and fluid behaviour are within expected local bounds.

## 7.2 Meaning

Stable does **not** mean harmless.

A Stable-Strata Coreward Chasm may still be extremely dangerous.

Stable means the region behaves according to its known baseline rather than an active abnormal state transition.

---

# 8. Pressure Surge

## 8.1 Identity

A **Pressure Surge** is a regional state in which pressure relationships intensify, migrate or change across validated chambers/basins.

## 8.2 Possible Consequences

- safe pressure zones contract;
- dangerous zones expand;
- pressure doors reconfigure;
- settlements seal districts;
- fauna migrate;
- Vault Mollusc habitats shift;
- Blackwater boundaries move;
- mines become inaccessible;
- new pressure-safe cavities may appear.

## 8.3 Boundaries

Pressure Surge uses the established bounded pressure model.

It is not arbitrary global damage, per-voxel fluid/gas simulation or instant unexplained death.

---

# 9. Seismic Swarm

## 9.1 Identity

A **Seismic Swarm** is sustained heightened tectonic activity across a region.

## 9.2 Possible Consequences

- repeated tremors;
- route damage;
- new cracks;
- exposed deposits;
- Seismic Forest response;
- Coreworm movement;
- structure stress;
- Stoneflow activation;
- dungeon exposure;
- altered pressure relationships.

## 9.3 Precursors

Potential warning channels include:

- Seismic Crystal;
- Seismic Choir;
- fauna behaviour;
- tremors;
- geological sound;
- sensors;
- NPC expertise.

---

# 10. Gravity Drift

## 10.1 Identity

**Gravity Drift** is a state in which one or more regional gravity profiles move between validated configurations.

## 10.2 Possible Consequences

- route orientation changes;
- Inverted Cavern crossings become unsafe;
- Gravity Well centres shift;
- floating debris redistributes;
- farms lose orientation compatibility;
- Abyss Lift operation changes;
- fauna alter movement.

## 10.3 Boundaries

Gravity Drift cannot invent arbitrary gravity directions outside the region's supported profile set.

Transitions remain readable.

---

# 11. Stoneflow Cycle

## 11.1 Identity

A **Stoneflow Cycle** activates Stoneflow-capable geology.

## 11.2 Possible Consequences

- route burial;
- tunnel opening;
- foundation stress;
- mineral exposure;
- structural deformation;
- settlement relocation;
- archaeological exposure;
- Coreworm-route interaction.

## 11.3 Boundaries

Stoneflow is slow/bounded enough to telegraph, geographically constrained and mitigable through engineering where plausible.

It is not universal liquid rock.

---

# 12. Blackwater Upwelling

## 12.1 Identity

A **Blackwater Upwelling** intensifies or shifts deep brine/current/mineral/ecological conditions.

## 12.2 Possible Consequences

- shoreline movement;
- stronger currents;
- mineral concentration;
- Pressure Pearl habitat change;
- Brine Reed expansion/contraction;
- Blackwater Mat bloom;
- port closure;
- aquatic migration;
- nursery disruption.

## 12.3 Boundary

Blackwater remains a regional high-mineral seawater/brine system.

Upwelling does not convert it into a separate magical fluid.

---

# 13. Fold Shift

## 13.1 Identity

A **Fold Shift** changes known route topology between bounded valid relationships.

## 13.2 Possible Consequences

A route may:

- shorten;
- lengthen;
- close;
- expose a branch;
- reconnect elsewhere within Impossible Deep;
- isolate a settlement;
- create a new trade corridor.

## 13.3 Map Behaviour

Maps must update discovered route topology.

A Fold Shift is not random teleportation.

---

# 14. Void-Corrupted State

## 14.1 Identity

The **Void-Corrupted State** is a genuine external corruption overlay caused by Void provenance.

## 14.2 Possible Effects

- altered ecology;
- contaminated resources;
- hostile state changes;
- broken infrastructure;
- abnormal geometry;
- corrupted fauna;
- corrupted guardians;
- altered authority behaviour;
- portal instability;
- dangerous spread.

## 14.3 Scope

Corruption may affect one site, one route, one biome region or multiple connected regions.

It is not assumed realm-wide.

---

# 15. Regional State Compatibility

Compatible states may coexist.

Examples:

## Seismic Swarm + Stoneflow Cycle
- severe geological instability;
- route change;
- new deposits;
- structural risk.

## Pressure Surge + Blackwater Upwelling
- major Vault-Sea expansion;
- dangerous port conditions;
- aquaculture displacement.

## Gravity Drift + Fold Shift
- extreme navigation difficulty;
- route reclassification;
- anchor failure.

## Void-Corrupted State + Native State
- corruption overlays a Pressure Surge, Seismic Swarm or other native condition.

Not every theoretical combination must be supported.

---

# 16. State Compatibility Rules

The regional-state system must support:

- explicit compatible combinations;
- explicit incompatible combinations;
- deterministic conflict resolution;
- bounded state count.

It must avoid combinatorial explosion.

A state combination is implemented only where it produces meaningful gameplay/world consequences.

---

# 17. State Priority

Where states conflict, resolution should consider:

1. regional physical validity;
2. authored event priority;
3. existing persistent state;
4. corruption overlay priority where applicable;
5. save-safe deterministic fallback.

No random order-of-operations should decide world identity differently every load.

---

# 18. Regional State Duration

State duration may be:

- short-lived;
- seasonal/cyclical;
- event-bounded;
- semi-persistent;
- persistent until repaired/resolved.

Examples include brief Gravity Drift, prolonged Blackwater Upwelling, persistent sealed routes after Stoneflow and lasting corrupted regions until addressed.

# 22. Unloaded / Far Simulation

Impossible Deep event simulation may abstract unloaded regions.

- settlement evacuation;
- new safe chamber;
- blocked route;
- newly accessible resource region;
- Pressure Sanctuary overload;

# 37. Event Frequency Philosophy

Impossible Deep should feel dynamic without becoming exhausting.

The simulation should avoid:

- constant disasters;
- nonstop route invalidation;
- permanent settlement destruction loops.

Events should create adaptation, exploration, opportunity, risk and history.

Frequency tuning remains deferred.

---

# 38. Event Severity

Events may have bounded severity tiers/states such as local, regional and major.

Exact naming is implementation-owned.

Severity can affect area, duration, infrastructure damage, ecological consequence and required response.

No automatic global catastrophe scale is required.

---

# 39. Authority-Driven Events

Fixed Realm Authorities do not require separate permanent global event categories.

Instead, their actions instantiate or modify compatible event families.

Examples:

- Pressure Titan movement → Pressure Basin Shift;
- Blackwater Matriarch succession conflict → Deep Settlement Crisis;
- Fossil Crown awakening → Fossil District Exposure + Seismic Swarm;
- exceptional Coreworm → Coreworm Migration;
- Seismic World-Beast → Seismic Swarm.

This keeps the event system coherent.

---

- Seismic Forge → Seismic Swarm destabilises machinery;
- Blackwater Citadel → Blackwater Mineral Storm floods or isolates sections.

- shafts;

- dream paths;
- gravity routes;
- Blackwater routes.

# 54. Cross-Realm State Interaction
