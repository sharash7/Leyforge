# Retain the Python standard-library Brain CLI beyond bootstrap

## Context

LF-BRAIN-11 requires a versioned, offline-capable, headless command family. Python is available in the rebuild environment and allows the v0.1 implementation to avoid package and community-plugin dependencies.

## Proposal

Retain the R4 Python standard-library implementation as the supported Brain CLI until engineering governance accepts a replacement ADR or Decision.

## Status boundary

This is deliberately **proposed**. R4 may implement the reversible bootstrap mechanism, but an agent has no delegated authority to promote this long-term tooling choice to accepted.
