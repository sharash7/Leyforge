# ADR-0001 — Godot V1 platform foundation

## Context / Problem

Branch B identifies the Godot V1 platform choice as a foundational decision whose historical acceptance evidence must be reconstructed before implementation depends on it.

## Authoritative Constraints

- R8 gameplay permission is closed.
- No legacy POC runtime or inferred engine version may be installed as R5 evidence.

## Proposed Decision

Reconstruct the actual platform decision and evidence during the later architecture gate. Keep the dependency planned until an accepted ADR names the supported engine build and acquisition path.

## Reconstruction Basis

B-OPS-06 foundational ADR backlog and the current clean-rebuild boundary. This record is proposed and does not itself accept Godot.

## Reconsideration Triggers

- Architecture gate opens platform selection.
- Supported engine, licence, provenance and verification evidence are available.
