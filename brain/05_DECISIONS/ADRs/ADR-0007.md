# ADR-0007 — Authoritative persistent-state architecture

## Context / Problem

The first V1 world will make identity, ownership, save schema, migration and recovery decisions durable.

## Proposed Decision

Define and accept one authoritative persistent-state architecture before G2. Historical save formats remain evidence and may not silently become the V1 contract.

## Reconstruction Basis

B-OPS-06, ENG-GOV-08 and the G2 validator backlog.

## Reconsideration Triggers

- Registry architecture is accepted.
- The first persistent V1 world-state gate is ready.
