# ADR-0005 — Monorepo modular architecture

## Context / Problem

ENG-GOV-02 calls for architecture-led module ownership while leaving the final V1 directory tree open until critical discovery is complete.

## Proposed Decision

Evaluate a monorepo with durable module boundaries after the architecture-critical discovery gates. R5 installs only project-wide governance and Brain infrastructure.

## Reconstruction Basis

B-OPS-06 foundational backlog and ENG-GOV-02. No final game/Forge directory tree is locked here.

## Reconsideration Triggers

- Architecture ownership and dependency directions are approved.
- First implementation module is authorized.
