# ADR-0002 — Zylann Voxel foundation

## Context / Problem

Branch B lists the voxel foundation as architecture-critical. PRD-02 conditionally accepted Zylann Voxel Tools 1.7 for architecture/prototype work; the owner-locked PROD architecture selects it as the production voxel substrate. The owner accepted this ADR on 26 September 2026.

## Accepted Decision

Adopt **Zylann Voxel Tools 1.7** as the production voxel substrate paired with the accepted Godot 4.7.2 stable baseline. Zylann owns supported voxel storage, terrain editing, meshing, streaming and materialisation facilities; Leyforge retains semantic world rules, stable identity, authoritative mutation, gameplay, persistence coordination, content and Forge ownership behind a Leyforge-controlled provider boundary.

Acceptance of this ADR approves the provider family and ownership boundary only. It does not install or activate Zylann. P01 must choose and pin the exact compatible module or GDExtension edition/build, upstream commit/archive, hashes, licence materials, export profile and diagnostics before activation or completion.

## Reconstruction Basis

B-OPS-06 and ENG-GOV-15 provide the dependency and provenance rules. PRD-02 supplies the capability audit and conditional candidate finding; bounded R7 proof evidence establishes only proof-lane behavior. PROD-00 and PROD-03 carry the provider family into the owner-locked corpus. This accepted decision does not itself install the dependency.

## Reconsideration Triggers

- The owner approves, rejects or revises the PROD production baseline.
- P01 compatibility work cannot identify a supportable Godot 4.7.2 / Voxel Tools 1.7 production pairing.
- Required terrain, persistence, export, performance or lifecycle evidence disqualifies the proposed provider.
