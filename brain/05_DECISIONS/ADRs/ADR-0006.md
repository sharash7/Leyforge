# ADR-0006 — Registry and stable identity architecture

## Context / Problem

Registry identities will cross persistence, content and external-package boundaries. Branch B requires a stable-ID architecture before those systems are active.

## Proposed Decision

Reconstruct and decide registry ownership, namespace grammar, aliasing, retirement and projection behavior before G1 implementation.

## Reconstruction Basis

B-OPS-06, ENG-GOV-09 and the G1 validator backlog. Historical POC registry values are evidence only.

## Reconsideration Triggers

- PRD-07 proof work or later architecture decisions establish the V1 registry contract.
