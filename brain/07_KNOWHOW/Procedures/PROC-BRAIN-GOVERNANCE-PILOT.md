# Exercise the Brain-to-governance operating model

## Purpose

Provide a repeatable bounded pilot for proving that Brain navigation and engineering governance control real project work without duplicating authority.

## Prerequisites / Environment

- Certified R5 governance bootstrap.
- One non-gameplay repository task.
- Repository root as the working directory.
- R8 gameplay permission closed.

## Steps

1. Query a cross-domain subject and open the returned primary authority.
2. Create linked Task and Work records with explicit scope, risk, permissions and verification.
3. Present an architectural scenario and confirm ADR-required routing without inventing acceptance.
4. Run a harmless invalid-record fixture, confirm actionable diagnostics, and exercise a bounded waiver fixture.
5. Promote any reusable operating discovery to a Skill, Procedure or Shortcut record.
6. Introduce a stale generated index only inside a disposable fixture; detect it and regenerate from owning records.
7. Retrieve the legacy POC archive as historical evidence, resolve current authority, and reject automatic copy-forward.
8. Run the full stable validation entrypoint and preserve machine evidence.

## Verification of Success

R6-AT-001 through R6-AT-007 and the full repository gate pass, with each REBUILD-00 pilot task represented in the R6 receipt.

## Safety / Governance Constraints

This Procedure is reusable project knowledge, not engineering law. Do not edit canonical authority or a tracked generated index merely to make a pilot pass. Do not activate dependencies, accept ADRs, approve real waivers or begin gameplay.

## Lifecycle

The Procedure remains `testing` until R6 receives exact-commit evidence. It may become `validated` during certified closeout without changing its authority role.
