# Governed Brain Change Procedure

1. Read the current Handoff and relevant authority.
2. Create or activate a Work Record.
3. Query related Decisions, Risks, Conflicts and evidence.
4. Make the smallest authority-respecting change.
5. Regenerate machine-owned artifacts through their commands.
6. Run quick checks during work and the required full/certification profile at closeout.
7. Record evidence at the tested Git commit.
8. Close Work, update the active Handoff and regenerate indexes.
