Establish the smallest governed proof-only W1 fixture/runtime surface required by PRD-07, reconcile all 17 W1 proofs individually, and execute only those whose complete prerequisites become READY while retaining every real result and preserving the PRD-08 and R8 boundaries.

## Scope

### In Scope

- Extend the certified W0 proof infrastructure with W1 FIXTURE-02, FIXTURE-03, FIXTURE-09 and bounded FIXTURE-10 composition.
- Provide explicit authoritative owners, revisions, ownership/session epochs, versioned worker proposals, controllable completion order, deterministic RNG contexts, zero-Node distant state and fidelity transitions.

- Reconcile PRD04-PROOF-04, 13, 14, 15, 16, 17, 18, 19, 21, 23, 24, 25, 26, 33, 34, 63 and 68 independently.
- Allocate new `PRD07-RUN-*` IDs only when actual authorized execution begins, continuing after `PRD07-RUN-0013`; create matching `PRD07-EVID-*` records only from retained execution output.
- Retain PASS, FAIL, INCONCLUSIVE, INVALIDATED and rerun history without overwrite; update Brain state, exact boundary manifests, evidence, audit, change and handoff records at the governed package boundary.

- Production gameplay, ordinary R8 systems, a production Godot project, production dependency activation or archived POC copy-forward.
