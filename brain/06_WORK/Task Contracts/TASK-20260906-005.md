# TASK-20260906-005 — R7 W0 dependency, export readiness and proof execution task contract

## Objective

Establish the smallest governed proof-only Godot/Voxel Tools runtime and real client/headless export surface needed to move individual W0 proofs toward READY, then execute every proof that becomes validly READY while retaining exact evidence and preserving the R8 boundary.

## Scope

### In Scope

- Record the owner's acceptance of [[ADR-0008]] with its accepted date and authority trail.
- Select and verify exact R7 proof-candidate Godot and Voxel Tools identities, provenance, licences, artifacts, build flags, patch state, ownership and update rules.
- Build a clean proof-only runtime/provider adapter with identity, registry, coordinate/frame, WorldSession, read-model, provider readiness/failure and diagnostic fixtures required by W0.
- Produce real hash-verified client and dedicated/headless proof exports and run their smoke lanes.
- Re-evaluate all 13 W0 proof prerequisites individually.
- Allocate `PRD07-RUN-*` only when a READY proof execution actually begins; retain append-only evidence and create `PRD07-EVID-*` only from the resulting real execution.
- Repair bounded proof-fixture/runtime defects through governed change control, using new run identities for reruns.
- Update Brain records, dashboards, dependency state, boundary manifests, receipts and the continuation handoff; commit, push and confirm required CI.

### Out of Scope

- Production gameplay, ordinary player-facing systems, R8 implementation or a production dependency/architecture decision.
- Accepting ADR-0001 through ADR-0007 or silently resolving [[CONFLICT-0002]].
- Copying archived POC code, content or dependency packages into the clean rebuild.
- Treating synthetic harness tests as proof evidence or inventing PRD-08 results.
- PR, merge, tag or release.
